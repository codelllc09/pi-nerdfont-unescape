# pi-nerdfont-unescape

一个让 Nerd Font 图标在 pi 的回复里保持完整的扩展。

有些模型在回答时会把这类图标弄丢。Nerd Font 图标是 Unicode 的私用区字符，
模型的输出流会把它悄悄吞掉：你要一个 Python 图标，回来时那个位置却是空的——
不报错，也没有任何提示。这个扩展让模型改用普通文本书写图标（`\uE235`），
再在回复到达你面前之前把它还原成图标。

## 它的边界在哪

它**没有消除**静默失败，只是消除了大部分，并把剩下的变成可见的。准确地说：

| 它能做到 | 它做不到 |
|---|---|
| 模型用转义（`\uE235`）写的图标能穿过输出流并被还原 | 模型写裸字符、且输出流在消息**到达之前**就吞掉——没有留下任何可检测的痕迹 |
| 没有可用字形的码位显示为可见的 `□U+XXXX` | 若你的终端用检测链之外的字体渲染，字形仍可能是豆腐块——检查只信任它能读到的字体 |
| 在**流内部**可见的丢字，会连码位一起报告 | 发生在更上游的丢字没有任何信号 |
| 代码块永不改写 | — |
| 你发出的消息在发送前被转义 | — |

一句话：它修的是它能看见的丢失，并且明说它看不见什么。它修不了模型的输出流。

## 安装

```bash
pi install npm:pi-nerdfont-unescape
```

重启 pi 即可。Linux + fontconfig 下开箱可用。

可选：装上 `python3` 与 [fontTools](https://fonttools.readthedocs.io/)（`pip install fonttools`）
以启用字形查询与排版渲染。不装也能用，只是扩展会告诉你哪些查询它做不了。

> 尚未发布到 npm。首次发布前请用：`pi install /path/to/pi-nerdfont-unescape`。

本包**没有运行时依赖**——`typebox` 声明为 *peer*，因为 pi 本来就提供它。

## 日常会有什么变化

| | |
|---|---|
| **按名字要图标** | 写 `[[nf:python]]`，消息落地时变成真字形（*beta：只在你本机已装字体里解析*） |
| **自己粘贴图标** | 发出前自动转义，模型收到的是你真正打的内容，而不是一个洞 |
| **复制配置片段** | 代码块与行内代码里的转义一律不动——复制出去还是原样 |
| **看见缺了什么** | 扩展**能判定为画不出**的字符显示成 `□U+E5EE`，而不是空白 |

## 怎么用

| 你想要 | 可以这样说 |
|---|---|
| 列表或标题里的图标 | “Python 那一项用 `[[nf:python]]`” |
| 查某个图标的正确码位 | “查一下 docker 图标” · “U+E0A0 是什么” → `nerdfont_lookup` |
| 对齐的表格、状态栏、海报 | “把这段渲染成带框表格” → `render_preview` |
| Starship 某模块的默认符号 | “starship nodejs 的符号” → `nerdfont_lookup` |

两个工具读的都是**你本机装的字体**，所以结果和你终端真能画出来的内容一致。
扩展绝不猜码位。

## 看起来不对时

| 你看到的 | 原因 | 怎么办 |
|---|---|---|
| 消息里出现 `□U+E5EE` | 这个码位在你的终端字体链里没有字形——或者字体链识别不出来 | 装一个 Nerd Font 并设为终端字体；方框后面就是确切码位 |
| 图标完全不见了 | 模型写了裸字符而不是转义，输出流在任何人看到之前就把它吞了 | 让它写转义形式（`\uE235`），或用 `[[nf:name]]` 标记 |
| `could not be resolved — font lookup unavailable` | 缺 `python3`（或 fontTools） | `pip install fonttools`；不管它也行，其它功能照常 |
| 围栏里显示 `\uE235` | 这是故意的：代码保持字面，方便复制 | 无需处理 |

## 设置（全部可选）

| 变量 | 默认值 | 何时需要 |
|---|---|---|
| `PI_NF_FONT_PATHS` | fontconfig 的 `monospace` 链 | macOS、Windows，或终端字体不是 fontconfig 的 `monospace`：指向字体文件/目录（用平台路径分隔符） |
| `PI_NF_CMAP_CACHE` | `~/.cache/pi-nerdfont-unescape/cmap.json` | 想挪动字形缓存时；可以随时删，下次会话重建 |
| `PI_RENDER_ALLOW_ANY` | 未设置 | 允许 `render_preview` 写到工作目录与 `/tmp` 之外 |

## 已知边界

- **`[[nf:name]]` 是 beta。** 名字只在你本机已装的字体里解析，不查别处。
- **四空格缩进的代码块不当作代码**——它与列表续行无法区分，猜错会静默破坏别处的还原。
- **会话存档里存的是还原后的字符**（这就是你看到的、也是重新加载的内容）。若模型之后
  照抄而不是写转义，仍可能被吞。
